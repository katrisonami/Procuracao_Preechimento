Este código fiz no meu primeiro estágio na area de cadastro onde eu preenchia manualmente e mensalmente procurações para serem renovadas e posteriormente assinadas pelos clientes e posteriormente autenticadas em cartório. Uma atividade demorada e propensa a erros, nela vi a oportunidade de automatizar e alem de poder aprender também fazer mais coisas no estágio.

É um código simples mas eficaz, ele lê o arquivo da procuração e o preenche com os dados dos clientes que estão no banco de dados geral, nisso ele preenche os campos automaticamente já com a data do próximo vencimento, um aatividade que demorava metade do mês começou a ficar pronta em 2 dias. Meu primeiro projeto em python pra me ajudar no trabalho, jamais esquecerei.
